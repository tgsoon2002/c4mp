# Code of Conduct

This project adopts the Contributor Covenant, version 2.1, as its code of conduct:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

It applies in the project's issues, pull requests, discussions and any space where someone represents the project.

To report behaviour that breaks it, use GitHub's "Report content" on the comment, issue or pull request. You can also
open a private security advisory on the repository (Security tab) and ask for the maintainer, Kien Nguyen. Reports
are handled privately.
